# Déclaration d'usage de l'IA

Conformément au règlement de la CADEV 2026, l'équipe déclare l'usage suivant.

**Outil** : Claude (Anthropic), modèle Claude Opus, utilisé dans Claude Code comme assistant de programmation.

**Parties concernées** :

- architecture de l'application et schéma de la base ;
- code Python (`app/`), gabarits HTML (`app/templates/`), feuille de style (`app/static/style.css`) ;
- tests automatisés (`tests/`), CI, Dockerfile, script de vérification des licences ;
- rédaction du README et des textes de l'interface.

**Œuvre de l'équipe** : choix du sujet et du concept (connecteurs africains à état vivant),
les trois connecteurs d'origine et leur documentation, les demandes initiales (besoins réels
du représentant de l'équipe), la relecture, les essais et le déploiement.

**Traçabilité** : les commits produits avec l'assistant portent la mention
`Co-Authored-By: Claude`.

**À l'exécution** : la plateforme n'appelle aucun modèle d'IA et n'envoie aucune donnée
d'utilisateur à un service d'IA.
