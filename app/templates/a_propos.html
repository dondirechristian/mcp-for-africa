Brancher un agent IA

Les développeurs construisent de plus en plus avec des agents IA. Un agent qui doit encaisser un paiement à Ouagadougou ou lire un registre à Abidjan ne sait pas quel connecteur existe, ni s'il marche encore. MCP for Africa le lui dit.

Serveur MCP

MCP for Africa expose son catalogue par le Model Context Protocol, en transport HTTP sans état :

{{ url_mcp }}

Dans la configuration d'un client MCP (Claude, Cursor, VS Code…) :

{
  "mcpServers": {
    "mcp-for-africa": { "type": "http", "url": "{{ url_mcp }}" }
  }
}

Deux outils, en lecture seule :

  • chercher_connecteurs(recherche, pays, categorie) : les connecteurs qui correspondent, avec leur état et la raison de cet état ;
  • demandes_ouvertes(pays) : les besoins déjà exprimés, pour ne pas construire en double.

API JSON

  • /api/connecteurs (filtres ?pays=BF&categorie=paiement)
  • /api/connecteurs/<slug>
  • /api/demandes
  • Documentation interactive

Comment l'état est calculé

Un connecteur est Vivant si un dev a confirmé qu'il marche ces 60 derniers jours, ou si ses tests automatiques passent et que son code a bougé ces 6 derniers mois. Il est Signalé cassé si le dernier essai a échoué, si ses tests échouent ou si son dépôt est archivé. Sinon il est À vérifier. La fiche dit toujours pourquoi.
